# 이전 maccel 안내

이 문서는 이전 이미지에서 사용하던 `maccel`/`regulus-maccel` 경로의 안내를
대체한다. 현재 framework `main`에는 해당 target이나 runtime이 없으며, Regulus의
공식 실행 경로는 `mobilint-regulus` target과 내부 `qbruntime` adapter이다.

현재 보드에서 실행·측정하는 방법, NPU-only 증적 조건, 결과 해석은
[Mobilint Regulus qb Runtime 실행 가이드](mobilint-regulus-runtime.md)를 따른다.
이전 결과의 `regulus-maccel`, `mobilint_accel` 표기는 historical evidence로만
해석하며 새 비교 결과에 사용하지 않는다.
